## 📖 About The Project

African Chess Academy is a modern full-stack platform built to support the digital transformation of chess education and academy management.

The platform goes beyond a traditional academy website. It provides an interactive digital environment where students can learn chess, play against a computer, participate in tournaments, track their ELO ratings, and interact with academy resources.

Different user roles, including students, coaches, and administrators, have access to features designed around their responsibilities.

The goal is to create a centralized chess ecosystem that combines:

- 🎓 Chess education
- ♟️ Interactive gameplay
- 🏆 Competitive tournaments
- 📈 ELO rating systems
- 👨‍🏫 Coaching
- 👥 Student management
- ⚙️ Academy administration

# ✨ Core Features

## ♟️ Interactive Chess Experience

- Interactive chessboard
- Play chess against the computer
- Legal move validation
- Chess game logic powered by `chess.js`
- Modern responsive chess interface
- Interactive learning experience

Players can track their chess progression through a rating system.

Features include:

- Rating progression
- Competitive rankings
- Tournament performance tracking
- Player statistics

## 🏆 Tournament System
