# African Chess Academy (ACA)

Premium chess academy platform built with Next.js + Supabase.

## Features
- Public website (Home, About, Programs, Coaches, Tournaments, Events, News, Contact)
- Real auth (email/password)
- Student portal (learning, lessons + interactive chess boards, tournaments, events, certificates, profile)
- Play vs Computer with real minimax AI and dynamic ELO rating updates
- Coach portal
- Admin CRUD (students, courses, tournaments, events, news)

## Tech Stack
- Next.js (App Router) + TypeScript + Tailwind CSS
- Supabase (Auth, PostgreSQL, Storage)
- Vercel deployment
